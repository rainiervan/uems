# University Events Management System
A simple university events management system built using the [Django](https://www.djangoproject.com/) framework.

## Quick Overview
This system allows administrators to efficiently manage university events and related information such as its timeframe and locations.

## Requirements
This project works best with Python 3.12 and later.

## Setting Up
To set up the system, clone the repository locally then set up a virtual environment for the installation of the required packages, outlined in the requirements file at the root folder.
